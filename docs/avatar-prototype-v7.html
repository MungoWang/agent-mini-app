monogram = 中文名前两个字拼音声母（待办→DB…），集成时 manifest 加 acronym 或引拼音库。 meta 版本号改为 commits 数（app 无 version 概念，以历史提交次数为准；原型为示例值，集成时 host 侧 ctx.bash git rev-list --count HEAD 或 runtime 计数器）。 ① 海报：渐变字 + 光晕；② 蚀刻：空心描边字 hover 填充；③ 印刷：线框邮戳 hover 黑白反转；三者纵向均为同款微缩白卡 + hover 提升。
