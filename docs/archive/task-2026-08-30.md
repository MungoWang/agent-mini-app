### hostPort 健壮性修复（验证时发现，已一并修）
- **SSE 挂起**：`HttpGateway.closeHttp` 用 `server.close()`，会被 `/api/events` 长连接挂住 → 改 port 的 in-place 重绑卡死。修法：`closeHttp` 先 `server.closeAllConnections()` 强制断连，再 close。**现在改 port 立即生效（host 即时重绑到新端口），无需重启**。
- **端口被占会崩掉整个 dsh web**：`host.apply` 抛 `HOST_LISTEN_FAILED` → 插件 `apply` 抛异常 → cordis 崩进程。修法：dsh 插件 `apply` try/catch，bind 失败时打印可操作错误并返回无副作用 dispose（dsh web 存活）。**现在端口被占 dsh web 不崩**，提示「Free the port, or edit host.json (hostPort) then restart」。
- **浏览器用户看不到原因**：`console.error` 只进 dsh 服务端终端，浏览器里点开面板只见泛泛的「Failed to fetch」。修法：panel `readJson` 网络层失败抛 `HostUnreachableError`（带 url），`actions.fetchApps` 对中文/英文分别显示可操作文案「无法连接小程序 host（url）：host 未启动或端口被占用。请释放端口，或编辑 runtime/host.json 的 hostPort 后重启。」**已在真 dsh web（端口被占）验证**浏览器里能看到此文案。
